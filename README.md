# Obee App Mockup

## Hướng dẫn chạy local

Yêu cầu Node.js `22.18+` hoặc `24.x` và pnpm `11+`. Khuyến nghị dùng đúng
phiên bản trong `.node-version` và `package.json`.

```bash
corepack enable
pnpm install
pnpm dev
```

Chạy các lệnh trên ngay tại thư mục gốc. `pnpm install` sẽ tự động cài workspace
trong `/web`; không cần `cd web`.

## Đường dẫn truy cập

- `http://localhost:5666/` (giao diện mockup web)
- `http://localhost:5666/mobile/` (giao diện mockup mobile)

## Tài khoản demo

Tài khoản demo đã được mock ở tầng request. Có thể nhập bất kỳ mật khẩu nào để đăng nhập bằng tài khoản quản trị mặc định.
